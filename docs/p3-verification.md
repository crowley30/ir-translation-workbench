## 交付行为与边界

三层术语支持新增、完整修改和停用；项目同位置候选先于全局，基金/技术按显式优先级，同优先级不同选择不代选。源词按整词、大小写和最长包含短语匹配，不替换原文或机器输出。适用说明是人工/模型资料，不能自动推断任意语义；同目标共赢记录保留全部说明并合并允许译法。三条示例默认停用，非权威。

文本和 DOCX 创建时保存项目、背景与术语副本；全局编辑不改历史。用户重新应用先看完整字段前后差异，再明确勾选确认。10分钟、单次、任务与库版本绑定的预览校验拒绝陈旧/跨任务/重复请求；应用只更新快照和复核依据，全部段落、人工文字、版本和 DOCX 映射不变。旧快照最多20次并只读，满额拒绝继续追加。

复核从已保存文字生成数字/币种/日期/比率、空译/疑似遗漏和术语提示，含精确 UTF-16 位置与原因。明确格式可进行十进制字符串等值比较，歧义格式标不确定；无提示不等于正确。每段80项常规提示上限并附人工完整核对说明，片段最多240 UTF-16单元。确认只能来自用户动作，绑定段落版本/快照；保存、重译和重新应用使对应确认失效。当前状态与最近100条事件可重开恢复，旧任务不自动套新库。

provider 注入契约真实携带文体、项目、背景、快照、已解析术语和最多各1,000字符的前后原文；测试只用注入 stub。mock 保留原文并标明占位及参数数量，不模拟专业翻译或解释。独立辅助解释入口明确尚未实现、保持禁用，不写回或导出。

离线 API 设置保存协议、地址、模型和服务端变量引用，显示配置/凭据状态，不接收或回显密钥值。只有 OpenAI-compatible 请求契约，其它协议尚待适配；设置不会切换适配器、解析 DNS 或测试连接。服务端静态地址校验拒绝常见私有/元数据/编码绕过。**生产真实 transport 本轮保持关闭，旧环境开关也无法启用；未来需另行验收 DNS/目标固定、TLS、重定向、供应商协议与预算。** 这项默认调用限制按用户本轮新增要求收紧，原 readiness 断言相应改为“配置未验证、不可调用”。

## 失败、独立审查与修正

- 独立审查发现同目标共赢术语的允许变体未合并，以及 `.5`/括号数字被误读为普通整数。新增回归修复前7失败、原64通过；修复后72项复核测试通过。前者合并允许集合而保留指导，后者明确不支持，不扩展为猜测财务格式。
- 配置页折叠会丢草稿、旧GET可能回退成功PUT的版本，已改为首次成功读取后保留草稿、明确重读时确认、请求代次和版本保护；两条浏览器回归通过。默认禁用示例版本为0时不能启用的问题也已补API回归。
- 新离线浏览器首跑2失败/2通过：一项是 Playwright 对 disabled option 的 matcher 不适用，现直接断言原生 disabled 属性；另一项是新增的放弃草稿确认被测试默认取消，现明确接受并检查提示。没有降低产品拒绝/保留断言。

## 试用门禁与剩余限制

仅限单人本机服务，无登录、公开部署或云端访问控制；SQLite无应用级加密。没有真实用户材料、真实密钥或外链获取，没有合并、发布和部署。未保存网页草稿不保证刷新恢复；配置折叠与任务切换保护不等于浏览器持久化。

确定性规则不是专业财务/合同审校：多重集不能证明相同数值绑定了正确指标，术语备注不等于自动语境理解，长度阈值不能证明完整性。未知数值格式或合理改写可能提示复核；没有提示也可能漏错。不做企业知识库、RAG、自动术语学习或自动审签。

供应商/协议验证、安全真实连接、服务端凭据管理和预算、Microsoft Word人工打开，以及未来是否部署和如何访问，均按 [试用前置条件](p3-evaluation.md) 后置。本轮完成后停止，等待父任务独立验收。
