## 交付行为

上传原始 DOCX 字节后，服务在受限内存中验证 ZIP 和整个 XML/关系包，返回持久化的规范结构与预检查报告。阻止项不可绕过；明确的排版降级必须确认。创建任务仅消费同一份报告/结构，并对同一 import ID 实施幂等创建。原始上传文件不落盘。

正文、1–6 级标题、受支持 bullet/decimal 列表、矩形简单表格、空段落及单元格多段落保持顺序和固定 ID。空结构留在文档树，不发送翻译请求。普通合成样本为 6 个正文块、11 个结构段落（10 个非空、1 个空）、1 张 2×2 表格和 4 个单元格；表格内共 6 段，顺序是 Metric / Quarter / Value / Revenue / USD 12 million / Synthetic estimate。

译文继续使用原有服务、段落版本保护和 SQLite。导出依据稳定 ID 读取已保存译文；完整性、映射或资源检查不通过则拒绝导出，不原文回填或截短。双语在同一段落/单元格内按原文后译文配对。导出构建全新的包，不复制原始宏、外链或未知部件。

## 安全与明确边界

- ZIP：5 MiB 上传、256 条目、20 MiB 累计解压、8 MiB 单普通部件、2 MiB 单 XML/关系部件、100 倍压缩比。实际流读取量和 CRC 与声明共同校验；拒绝路径穿越、规范化冲突、重复、加密、链接和不支持压缩。
- XML：仅有效 UTF-8，禁止 DTD/实体声明；整个包最多 100,000 节点、深度 80。关系仅在包内解析，不访问 URL。
- 文档：100 个段落（包括空段和表格段）、20,000 字符、20 表格、200 单元格、10 列；超限拒绝，不返回伪完整文档。导出另限 1 MiB 累计文字，校验输出包与 XML 大小、非法控制字符。
- 图片/图形、文本框、真实脚注/尾注/页眉页脚内容、批注、修订、嵌套/合并表格、域、未知内容和含义不明的格式阻止。仅真正空的头尾、系统注释分隔符可告警。未知 `customXml` 也会阻止，即使外观简单。
- 支持 Transitional OOXML 的常见主部件路径；严格 OOXML、特殊布局、复杂编号重启等明确不支持。列表导出使用固定可读编号/项目符号，需要知情确认，不会自动续号。不承诺逐页原样。
- 仅合成 fixtures、mock 与注入响应。没有真实材料、真实凭据、外链获取、宏执行、收费 API、合并、部署或发布。
