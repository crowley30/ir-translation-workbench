# P3 离线服务设置契约

本轮按用户「暂时不接 API」的要求，只保留自定义接口与非敏感设置。没有真实凭据、连接测试、DNS/服务商请求或费用；保存配置不是验证兼容性。当前生产真实请求通道关闭，即使旧环境变量显式启用也不能调用；只有注入的离线 stub 可用于契约测试。

## 接口与持久化

`GET /api/provider-settings` 返回模式、协议、baseUrl、model、credentialRef、revision、时间与安全状态。`PUT` 提交完整非敏感字段和 expectedRevision；冲突返回409，未知字段/密钥字段返回400。JSON 与来源校验沿用主 API。只保存 SQLite 的 `app_settings` 非敏感 JSON；设置不修改任务、术语快照或运行中的翻译适配器。

状态区分 mock、未完整配置、配置已保存但未验证。凭据引用只允许 `TRANSLATION_API_KEY` 或 `IR_TRANSLATION_*_KEY` 等服务端约定名字；响应仅说明变量存在或缺失，永不回显值或其末尾字符。此设置页没有密钥输入框，不使用 localStorage，不提供明文密钥存储。用户不应向任何配置字段粘贴秘密；已知密钥形态、额外字段会被拒绝，但这不是对任意秘密的自动识别保证。

界面普通折叠/展开保留未保存草稿；明确重新加载才恢复保存状态，有草稿时先确认。异步读取不能覆盖更高保存版本，重复点击不会创建并发写入。15秒期限覆盖响应正文，超时/取消仅停止本地等待，不声称服务端修改回滚；之后重新读取确认。

## 协议与 URL 的边界

当前只实现标准 OpenAI-compatible 的结构化请求契约（文体、项目背景、快照、相关术语、相邻段落），不声称所有自称兼容的厂商都可使用。协议选项保留未实现的其它适配器入口；不猜测认证、响应或错误格式。配置的 base URL 不会被拿来发送请求。

纯服务端静态校验只接受 HTTPS、多标签 DNS 命名形式和默认/443端口；拒绝全部 IP 字面量与数字变体、已知本机/内网/元数据名字、凭据/查询/片段、控制字符、反斜杠、编码主机及路径混淆。错误不回显原始 URL、秘密或内部异常。`urlValidation=syntax-only-no-dns` 明确说明这不证明该名称解析为公网。

不执行连接意味着保存地址不能触发内网访问或跟随重定向。**静态检查不等于安全的真实请求。** 未来启用生产请求前必须完成并验收：解析所有 A/AAAA 并拒绝私有/链路本地/元数据等目标、连接固定到已验证的目标、TLS 主机校验、禁止重定向及逐次重新校验，且需要用户另行授权服务、凭据和预算。当前不实现或试运行这条真实网络通道。

## 离线验收

单元/HTTP 合成测试覆盖地址绕过、字段校验、凭据值不回显/不落库、SQLite重开、版本冲突、来源保护、设置不激活适配器以及 fetch/DNS零调用。浏览器验证保存/刷新、草稿保留、迟到读取及错误恢复。实际命令、退出码和限制写入 [P3 执行记录](p3-verification.md)，不以本契约中的计划冒充已运行。
