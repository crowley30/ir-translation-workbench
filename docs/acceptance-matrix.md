# 验收矩阵

以下是验收目标；实际通过、失败或未运行状态以 [执行记录](verification.md) 为准。所有样本均为合成内容，mock 结果只证明流程行为。

| ID     | 范围           | 操作与合成输入                                           | 预期结果                                                    | 建议证据                         |
| ------ | -------------- | -------------------------------------------------------- | ----------------------------------------------------------- | -------------------------------- |
| P0-01  | 启动与模式     | 无凭据启动                                               | 中文桌面界面可用；醒目 mock 标识；无真实 API 请求           | 启动命令、浏览器截图、适配层测试 |
| P0-02  | 服务配置       | 真实模式但缺少配置                                       | 明确不可用，不降级成伪真实译文；浏览器无密钥                | 配置测试、构建产物检查           |
| P1-01  | 文本与文体     | 多段英文，分别选择忠实合同/商务文体                      | 文体随任务保存；原文与逐段占位内容对齐；模式仍清晰          | 集成与浏览器检查                 |
| P1-02  | 空与超限       | 空串、全空白、超过 20,000 字符、超过 100 段              | 前后端校验；拒绝创建无效任务；错误可见                      | 校验单测/API 测试                |
| P1-03  | 保存与恢复     | 修改第二段，保存，打开其它任务，再返回；刷新             | 已保存译文与人工编辑标记不丢失                              | SQLite 重开测试、E2E             |
| P1-04  | 局部重译       | 修改第二段；仅重译第一段                                 | 第二段及其它段保持原样                                      | 版本与局部更新测试、E2E          |
| P1-05  | 在途编辑       | 启动慢请求，修改目标段并保存，等待结果                   | 旧请求不覆盖新的人工作品；状态可理解                        | 并发集成测试                     |
| P1-06  | 重复点击       | 同一任务连续点击运行/发送并发请求                        | 一个运行生效；重复请求明确拒绝；无重复写入或无限重试        | API 并发测试、浏览器检查         |
| P1-07  | 取消与重试     | 启动慢运行后取消，再重试未完成段                         | 停止后续请求；已完成内容保留；取消状态落盘；可恢复运行      | API 与 E2E                       |
| P1-08  | 超时           | mock timeout                                             | 有限尝试后失败；错误可见；可重试                            | 适配层次数断言                   |
| P1-09  | 限流与服务错误 | mock 429 / 5xx                                           | 按策略有限重试；成功/最终失败分类正确，无服务商敏感响应泄露 | 适配层与集成测试                 |
| P1-10  | 部分失败       | mock partial，多段文本                                   | 成功段保留；任务显示部分失败；只需重试失败段                | 集成测试与浏览器检查             |
| P1-11  | 格式错误       | mock malformed/真实适配器合成非法响应                    | 不把错误响应保存成译文；记录安全错误                        | 格式校验测试                     |
| P1-12  | 导航与重启     | 运行期间刷新/切换任务；服务重启后重开数据库              | 已保存内容保留；运行状态不永久卡住；可取消或重试            | E2E、服务重启恢复测试            |
| P1-13  | 复制与导出     | 编辑并保存后复制/下载文本                                | 导出当前已保存译文，段落顺序一致，mock 标识保留             | E2E 文本断言                     |
| P1-14  | 存储冲突       | 旧版本提交人工编辑                                       | 明确版本冲突，已有新版本内容保留                            | 乐观并发测试                     |
| P1-14b | 草稿恢复       | 保存请求期间继续输入；模型先返回后保存；配置首次读取失败 | 新草稿保留且可再次保存；版本冲突需确认；服务恢复后按钮可用  | 浏览器回归测试                   |
| P1-15  | 公开仓库检查   | 检查暂存 diff 与忽略规则                                 | 无密钥、真实样本、数据库、临时测试产物；只含项目文件        | 检查命令、Git 状态               |
| P1-16  | 工程检查       | lint / 类型 / 单元集成 / build / 浏览器                  | 记录每条命令、退出码与报告；环境阻塞如实保留                | 执行记录                         |
