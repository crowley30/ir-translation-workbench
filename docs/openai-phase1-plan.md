## 本阶段目标

保留现有 mock、文本/DOCX、术语快照、确定性校对、人工确认和版本保护。增加官方 OpenAI Responses adapter，使用带稳定段落 ID 的严格结构化结果、模型选择、令牌限额、可取消/超时/有限重试和安全错误。OpenAI-compatible 自定义接口保留为单独协议扩展/离线配置，本阶段只允许固定官方目的地址进入真实传输；自定义域名不能因通过字符串校验就被发送请求。

服务端 HTTPS 传输需核验 DNS 全部结果并固定连接地址、校验 TLS/SNI、拒绝重定向和私有/特殊用途地址。仅显式用户翻译动作才能调用；页面加载、读取配置、保存设置和启动服务都不测试连接。真实调用同时要求服务端操作员开关、受限累计预算、服务端凭据存在、支持的定价模型，以及用户明确启动。默认 mock 且真实调用关闭；本轮不得设置这些真实条件。

预算是首次真实测试一轮的所有请求累计，含并发与重试。每次发送前按输入保守上界与最大输出预留，不足不发送。用量可信时对账；未知、取消、失败或进程中断保留上界，不能直接释放后无限重试。余额和预留持久化，再启动不重置。未知定价模型阻止真实调用；估算不构成供应商账单绝对硬限额。用户现已确认首次真实测试累计 1 美元，含全部请求与重试；此确认仅移除预算待确认项，不授权本轮配置密钥或发真实请求。代码不把所有未来使用永久限制为 1 美元，使用服务端操作员上限与当前测试账本；不依赖赠金或邮件到期时间。

## 用户最小配合路径与真实门禁

只在后续获准时配置服务端 `OPENAI_API_KEY` 引用，不在聊天、浏览器、数据库、日志或仓库填写值。已查阅当前官方 Codex Cloud 文档：环境配置中 Manage → HTTP secrets，或 Settings → Codex Cloud → Personal vault → Add → Network secret；绑定环境所请求的变量名，目的域限定 api.openai.com 的 HTTPS 443。官方说明进程得到占位符、网络层仅为允许目的地注入值，不能沿用“所有 secret 仅 setup 可见”的旧结论。

本环境未提供可调用的凭据管理工具，不会读取或配置秘密。本项目本轮仅实现直接服务端环境变量的固定 DNS/TLS 传输，尚未实现该 Cloud 网络 secret 代理路径，也未联调，不能保证占位符可用；这是后续 Cloud 安全试跑前需补齐并独立验收的门禁。自托管本机服务可由操作系统/进程管理器注入真正的服务端环境变量，避免写入文件，不能把值复制到网页。现阶段只实现变量引用与安全状态，不配置真实密钥。官方文档链接和协议/模型核实记录会单列，不查询真实组织余额或可访问模型。

## 任务与验收

1. 核实官方协议、结构化输出、当前可选模型/价格与 Cloud secrets；将明确模型与价格快照写入有界目录，未验证的 ID 不开放真实计费。
2. 实现传输、累计预算、Responses adapter、显式 live 控制和非敏感设置；保留 legacy mock/离线协议测试。
3. 界面显示 mock/live/关闭状态、当前模型、令牌/累计预算和明确启动/停止；不收密钥，不自动发请求。
4. 全部使用合成 stub/本地 fake transport：检查成功及 ID/完成状态/拒绝/截断/格式/用量、429/5xx/超时/取消、并发预留、重启未知费用、DNS/重定向边界、人工修改与术语数值复核；文本与 DOCX 都覆盖。
5. 全量 format/lint/type/unit/integration/build/browser/public scan，记录命令/退出码、截图与未运行边界；提交 push 并开 Draft PR，停待独立验收。

不做真实供应商调用、密钥创建/配置、部署、合并、专业质量评分或其它产品功能。赠金余额、适用模型权限和截止时刻均未知。

官方起点：https://developers.openai.com/api/docs/guides/text ，https://developers.openai.com/codex/environments/cloud-environments 。具体 API/模型依据以本轮核实记录为准。
