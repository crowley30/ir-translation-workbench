## 行为与安全门禁

生产服务始终从 mock 启动。非敏感服务配置新增官方 Responses 与有界模型目录；自定义 OpenAI-compatible 设置保留离线，不能借语法合法的 URL 发请求。官方传输使用固定 `api.openai.com:443/v1/responses`，验证所有 DNS 结果为允许的公网单播地址，每次连接固定已验证地址并保留官方 TLS/SNI 检查，无连接复用、重定向或自定义域名回退。DNS/响应头/正文都有取消和资源限额。

开启真实调用需要服务端操作员开关、非零操作员累计上限、合法官方配置、服务端凭据引用、已核对定价模型、版本一致及用户两项明确确认。启动/读取/保存/启用都不测试连接；只在明确翻译动作发送。停止/切 mock 先关闭预留权限再取消运行任务。任务保存 provider/model 来源，防止混入 mock 或其它模型结果；每次重启重新明确启用，不恢复真实连接。

每段请求都有稳定 ID、文体、源文、项目/上下文及已解析术语，不机械替换英文子串。严格 schema 之外应用仍核对 ID、数量、完成状态、角色、非空译文和输出限额；拒绝、截断、未知工具/状态不能假完成。原有术语冲突、数值提示、人工确认失效、修订版本和 DOCX 映射保护保持。默认每段输出 4096 token、范围 256–8192，完整序列化请求最多 64000 UTF-8 字节；长段触顶须拆分，不声称完成。

每次尝试先同步持久化预留完整请求 UTF-8 字节上界加 4096 token 协议余量，以及最大输出费用；已知目录按较高缓存写入输入价计算。可信 usage 才按保守费率对账，金额是估算而非供应商账单；不确定/取消/超时/失败和写入中断都保留上界。余额不足不发请求，重试独立占额，超出 usage/token 预留后关闭。单数据库当前只有一轮不可由网页重置的账本，最多 10000 次尝试；新一轮管理留待后续授权，不硬编码永久 1 美元。只计此服务发出的请求，不覆盖同账户其它客户端。

用户已确认后续首次真实测试累计 1 美元（所有请求和重试合计）；本轮仍不配置秘密或发真实请求。操作员默认预算 0，网页预算默认空白。未知价格、模型别名或计费 tier 不猜测；仅接受返回模型与目录 ID 精确一致、tier 为 default，未知情况拒绝并保留预留。

真正限流/可重试故障最多 3 次；计费耗尽、权限、模型、结构或确定性完成失败不自动重试。应用实际 Retry-After 等待上限为 2 秒，超过即停止并提示人工稍后重试，绝不提前重发。取消等待不能证明远端未执行或未计费。

首次未来试跑安全配置路径与官方模型/协议依据见 [官方核对记录](openai-official-reference.md)。当前 Cloud 文档的 Network/HTTP secret 提供 placeholder 并由 HTTPS 代理按域替换；本项目直接固定 DNS 的 native HTTPS 传输尚未实现 Cloud 网络密钥代理路径，也未联调，本阶段不能宣称 Cloud placeholder 能认证。这是当前 Cloud 真实试跑的工程门禁；只有直接服务端环境变量路径完成离线实现。没有可调用的密钥管理工具或实际 secret 配置；应在独立验收后由用户通过安全入口配合。自托管服务可用受控进程环境注入值，网页只填写变量引用。不要在聊天、网页、仓库或日志发送真实密钥。
