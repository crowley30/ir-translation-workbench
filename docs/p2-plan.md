# P2：DOCX 导入、预检查与基础导出计划

## 已验收基线与本轮授权

基线 commit：`22909dca2dfdfd86d44694cac35221d7d9f09b2c`。P0/P1 的文本输入、持久化编辑、任务恢复、局部重译保护和 **mock 工作流** 已由父任务验收。本记录不代表真实 API 可用、专业翻译质量合格或合同法律准确性通过。

本轮 P2 在该基线上增加有边界的 DOCX 上传、预检查、稳定结构映射，以及中文和双语 DOCX 基础导出。为本轮交付集中验收，基础导出由原总体计划的后续阶段纳入 P2；术语、解释、数字/币种/日期检查仍不在本轮实现。此计划先于 DOCX 实现写入，最终状态以实际验收记录为准。

继续仅使用合成样本、默认 mock，不设置真实凭据，不调用收费 API。不访问或修改 PowerQuery；不合并 `main`、发布 release、部署或扩大为多人系统。

## 产品边界

- 支持 DOCX 主文档中的普通段落、标题、常见编号/项目符号列表，以及无合并、无嵌套的简单表格。
- 保留空段落、空单元格和同一单元格内多个段落的顺序与位置。空段落作为结构节点保存，不因无法翻译而从文档映射中消失。
- 导入必须先展示预检查报告；有内容丢失风险的结构阻止导入，不能只警告后静默舍弃。
- 非文本视觉内容的降级单独提示，要求使用者明确确认。确认不代表有损文本可以被忽略。
- 导出只使用服务端已保存译文，保留可编辑的基础文档结构。中文和双语两种导出都不承诺原页码、分页、字体、图片、主题或精确版式还原。
- 页面和导出持续保留 mock 标识。中文模式中的占位内容仍是非译文，不能以 DOCX 格式包装成真实翻译。

## ZIP、XML 与包安全合同

输入文件名和 MIME 只作用户提示，不能代替 ZIP 与 OOXML 验证。资源边界至少覆盖上传字节数、ZIP 条目数、声明与实际累计解压字节数、单条目大小、压缩比、XML 深度/节点数、文本总长度和结构节点数。限值集中定义；界面展示上传和正文限额，完整资源边界写入运行说明，实际数值及边界测试随实现记录；不能只检查解压后的文本长度。

ZIP 条目不得写出到任意磁盘路径。拒绝路径穿越、绝对路径、重复/规范化后冲突路径、损坏 ZIP、加密包、宏内容以及不支持的压缩方式。不得信任中央目录声明而忽略实际解压大小；达到上限立即终止。不把未知文件扩展名改成 `.docx` 后继续导入。

XML 解析禁止 DTD、实体展开、外部实体和任何网络解析；按受限缓冲区解析，拒绝畸形或超过复杂度上限的输入。确认 DOCX 必要主部件、内容类型和关系映射有效；缺失、歧义或异常重定向不能用空文档代替。

不访问文件中的外部 URL，不下载关系目标，不执行宏、脚本或嵌入对象。未知外部关系、`altChunk` 等替代内容必须报告并阻止；允许的普通文本超链接只能保留显示文字并报告链接降级，不自动打开或在导出中带入外链。导出使用本地生成的新包，不能直接复制未审查的原始部件。

## 内容清单与处理规则

预检查报告至少包含文件信息、支持结构统计、可翻译段落数、空结构数、阻止项/警告项、可定位的部件与结构位置、被降级内容的影响。报告不能只显示「发现不支持内容」或只给异常代码。阻止项不得提供绕过导入按钮。

| 内容类型                                         | 本轮处理                                                                                                              |
| ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| 正文、标题、普通文本 run、明确的换行/tab         | 支持；合并为段落文本时保持字符与顺序，导出为可编辑段落                                                                |
| 常见编号/项目符号列表                            | 解析编号定义、层级和段落引用；导出以固定编号/项目符号文字和缩进保留，编辑不会自动续号；此降级需确认；复杂编号明确阻止 |
| 简单表格、空格、单元格多段落                     | 支持；使用行/列/段落位置及固定 ID；保持空格和段落覆盖                                                                 |
| 有内容的页眉/页脚、脚注/尾注、文本框、批注、修订 | 阻止；即使主文档正文可读，也不能以正文成功掩盖这些内容                                                                |
| 嵌套表格、横向/纵向合并单元格、复杂表格          | 阻止；不拆平后假装结构完整                                                                                            |
| 图表/SmartArt/带文字图形/嵌入对象、域或替代内容  | 含文本、引用值或无法确认文本完整性时阻止；不得把未知对象当成纯装饰                                                    |
| 无可解析 XML 文字的图片等视觉内容                | 默认阻止：图片可能承载文字和含义，本轮无 OCR，无法确认文字完整性；不能通过视觉确认绕过                                |
| 外部关系、宏、脚本、加密包、不合法包             | 按安全合同拒绝或阻止；零网络获取、零执行                                                                              |
| 字体、颜色、页边距、主题、页码/分页等视觉版式    | 可降级并清楚说明不保证版式保真；含动态文字或未知值的域仍阻止                                                          |

预检查必须扫描主文档以外的关系/部件，不能只查看 `word/document.xml` 就宣称没有遗漏。对于无法判定是否含有文字的对象，按有内容风险处理并阻止。

## 稳定映射与导出合同

保存原始包的受控元信息或指纹、解析结果版本、结构节点和固定 ID；段落映射显式指向正文块或表格单元格内的位置。同样文本出现在多个位置时是不同节点，不以文本内容作为唯一键。跨刷新、任务重开、局部重译和导出不重新分配 ID。

空段落不发翻译请求，但保留在结构中。空单元格和同单元格多段落的定位不能由非空译文数组下标推导。导出按结构树走访，不按翻译完成顺序拼接；部分失败、取消和人工编辑均沿用既有版本保护。

中文导出为每个可翻译节点放入已保存译文，双语导出在同一结构位置保留原文后放入对应已保存译文。标题、列表、简单表格和空结构保持基础语义；双语表格可以在同一单元格内按原译段落成对排列，不能把整张表改成无映射的散文。

导出前进行覆盖检查：缺失译文、映射缺失、未知结构或来源报告未确认时给出阻止理由；不得通过空串、原文回填或模拟占位来伪装已完成真实翻译。mock 导出允许验证流程，但页面、文件说明与内容持续注明模拟性质。

## 验收证据的界限

重新解析验证用于检查 ZIP/XML 有效性、结构和覆盖，必须尽量采用与生成逻辑独立的解析断言。可用的 LibreOffice 等渲染器可以辅助验证打开、分页和可见内容，但不等同 Microsoft Word 验收。若环境不能实际运行 Word，明确记录「Microsoft Word 人工打开检查未运行」，并保留该项验收门槛，不宣称兼容所有编辑器。

本轮不做 P3 术语/解释、真实 API 质量验收、PDF/OCR、邮件接入/自动发送、多人协作、公开部署或复杂知识库。达到 P2 出口后停止，向父任务返回准确分支、commit、draft PR、证据和剩余门槛。

### 本轮实现的明确限制

仅接受 Transitional OOXML 的常见 `word/document.xml` 主部件布局；严格 OOXML 或特殊主文档布局明确拒绝。空页眉页脚、以及仅系统分隔符的脚注/尾注部件可以告警后继续；一旦含文字、域或其它不能确认的内容则阻止。列表导出为固定可读编号/项目符号，不具备 Word 自动续编号语义。

集中资源限额：上传 5 MiB；ZIP 256 条目、累计解压 20 MiB、单普通条目 8 MiB、XML/关系单部件 2 MiB、压缩比 100；XML 全包 100,000 节点、嵌套深度 80；正文/表格总段落 100（含空段）、20,000 字符、20 表格、200 单元格、10 列。超限受控拒绝，不截短后标为完整。导出累计文本限 1 MiB，并验证生成包体积；无法无损表示的控制字符/CR 明确拒绝。
