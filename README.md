# IR 翻译工作台

面向科技基金 IR 的单人中文网页工具，桌面优先。支持英文粘贴，以及有边界的 DOCX 上传预检查、逐段审阅、人工编辑保存和中文/中英双语 DOCX 基础导出。

**默认是模拟模式：输出明确标注的占位内容，不是实际翻译。** 文本、有限 DOCX、术语和复核流程保留；本轮新增 OpenAI Responses 服务端接入与显式调用门禁，只以合成 fake transport 验收。未配置真实凭据、未调用收费 API，真实连通性和专业质量仍待独立验收。

## 运行

需要 Node.js 24 或更高版本和 npm。数据库使用 Node 自带 SQLite。

```sh
npm ci
npm run dev
```

打开 `http://127.0.0.1:5173`，前端代理访问 `127.0.0.1:3001`。云端 npm 默认缓存不可写时，使用 `npm_config_cache=/tmp/ir-npm-cache npm ci`。

构建后由单个服务端提供页面：

```sh
npm run build
npm start
```

打开 `http://127.0.0.1:3001`。服务仅监听本机，无登录或远程访问控制，不适合公开部署；公开仓库不等于公开应用。

## 文本与 DOCX 工作流

粘贴英文，用空行分段，选择「忠实合同」或「商务文体」后创建任务。文本路径保持原有限额：20,000 字符、100 段。创建期间原文和选项锁定；失败保留原文，模式变更不会自动开始另一种模式的翻译。

DOCX 请先选择 `.docx` 并点击「上传并预检查」。报告展示正文、标题、列表、表格、空段落及阻止/警告项，可以查看原文结构。仅结构可安全处理时才可创建任务；已知基础排版降级需要知情确认。预检查可取消，未开始模型翻译；同一份已确认导入重复创建会返回原任务。

原译逐段对照，表格段落标有单元格位置。保存人工修改后，可以刷新或从列表重新打开。局部重译只作用于选中段落，运行中保存的人工修改有版本保护；旧结果先到达时需确认后才能覆盖。失败或取消后可继续未完成段落。

全部文字段落完成并保存后，可导出中文或中英双语 DOCX，双语按原文后译文逐段配对；空段落、标题和简单表格结构保留。未保存草稿、缺失译文、部分失败或异常映射不能冒充完整文档导出。TXT 与复制功能保留。模拟任务的导出持续标明「模拟文档·非实际翻译」。

## DOCX 的支持边界

- 仅支持常见 Transitional OOXML 主文档布局：正文、1–6 级标题、明确的常见项目符号/十进制列表、无合并和嵌套的矩形简单表格。保留空段落及单元格内多段落的顺序。
- 列表导出为固定可读编号/项目符号和缩进，编辑后不会自动续编号；这项降级会告警并要求确认。
- 段落、字符、表格的直接格式与已引用样式继承链都会检查，包括默认样式、`docDefaults` 和表格条件样式。隐藏文字、删除线和双删除线可能改变可见内容或金额含义，按保守规则阻止；不会作为普通视觉降级忽略。
- 当前不是完整的 Word 样式级联解析器，不完整计算 toggle 叠加/取消后的最终有效格式；即使 Word 中某项隐藏或删除线效果已被后续格式取消，也可能因继承链中的风险格式被拒绝。`w15:restartNumberingAfterBreak` 的跨分节重启与 `docDefaults` 编号同样阻止。
- 不承诺原字体、分页、主题或逐页原样。普通视觉样式变化告警；图片、文本框、脚注/尾注、带内容页眉页脚、批注、修订、合并/嵌套表格、动态域及未知内容会阻止完整文档翻译。
- 图片可能包含文字和含义，本轮无 OCR，不能通过勾选确认绕过。仅空页眉页脚、系统注释分隔符等已确认无文字内容可以告警继续。
- 未知 `customXml` 等部件、复杂编号、严格 OOXML 或特殊主部件布局会明确拒绝/阻止，即使文档外观简单。请在 Word 中处理报告指出的内容后另存重试；不宣称所有 Word 文件受支持。
- 所审查的语义开关与默认样式中的非法 OOXML 布尔值、无命名空间的未知元素和畸形 XML 会拒绝导入；XML 首次发现结构/复杂度错误即终止解析，不继续扫描后才返回失败。布尔值支持 `true/on/1` 与 `false/off/0` 的合法表示，未知值不会默认当成关闭。
- 上传上限 5 MiB；总段落 100（含空段和表格段）、20,000 字符、20 表格、200 单元格、10 列。ZIP/XML 还有独立的解压、条目、压缩比和复杂度上限，见 [P2 任务书](docs/p2-plan.md)。超限拒绝，不截短后假完成。

没有执行宏、访问文档外链或复制原始可执行部件；只在受限内存中读取 ZIP，不按条目路径写盘。导出从已验证结构和已保存译文生成新包。真实 Microsoft Word 人工打开检查尚未运行；OOXML 重读与 LibreOffice 渲染不等于 Word 或专业翻译质量通过。

## 术语与人工复核

新建文本和 DOCX 共用「项目名称」与「翻译背景」。任务创建时复制当前启用的三层术语：指定项目、基金 IR、AI/具身智能。项目同位置候选覆盖全局；基金与技术候选按显式 0–100 优先级比较，同优先级不同译法显示冲突并阻止对应段落进入模型。整词、大小写和最长包含短语匹配避免把 `AI` 命中其它单词，或把 `business model` 中的短词直接替换。适用说明保留给人工与 provider，不假装自动理解语境。

「术语管理」可增改、停用、设置保留原文或允许译法。三条通用示例默认停用且非权威，人工译文不会自动升为规则。全局修改不改变历史任务；「项目与术语快照」提供完整前后差异，明确确认后只更新任务指导，保留全部原译文字和人工修改。旧快照只读保存，最多 20 次历史，满额拒绝继续追加。

每段「检查与人工复核」显示有限数字、币种、日期、比例、空译文/可能遗漏和术语提示，包括原译位置及原因。明确格式可等值换算，歧义格式交人工；没有提示也不能证明正确。只有点击人工确认才记录当前段落版本与快照，保存新译文或重新应用后确认失效。复制/TXT/DOCX 只使用已保存译文，不包含解释或提示。辅助解释尚未实现，入口明确禁用。

## 服务设置与 OpenAI 接入

「翻译服务设置」只保存非敏感的协议、基础地址、模型和服务端凭据变量引用。保留 OpenAI-compatible 自定义配置作为独立扩展入口，目前不对自定义地址发请求；不是所有厂商均兼容。新增 OpenAI 官方 Responses 协议，可选择已核对目录中的 `gpt-6-luna` 或 `gpt-6.1-terra`，固定官方地址。目录与价格依据见 [官方核对记录](docs/openai-official-reference.md)；模型账户权限、实际质量与价格适用性未真实验证。

「真实调用控制」独立于设置保存。服务启动、页面读取、保存设置及明确启用都不连接供应商，只有任务的翻译动作可能发送请求。默认真实开关关闭、操作员预算为 0。未来独立验收并配置服务端凭据后，还须同时满足操作员 `ALLOW_REAL_TRANSLATION=true`、非零 `TRANSLATION_MAX_BUDGET_USD`、官方协议/已定价模型、明确预算与数据传输确认，才能开始真实任务。关闭浏览器不等于停止服务端调用，请使用停止按钮；停止或切回 mock 会取消运行任务，已有真实任务不能混入模拟或另一模型的结果。

服务端只读取凭据引用所指的环境变量，不在网页接收密钥、不回显值或写入数据库/localStorage/日志/仓库。当前 Cloud 安全入口与其代理兼容性限制，以及自托管服务端最小配置路径见 [第一阶段计划](docs/openai-phase1-plan.md)。本轮没有配置真实秘密；不要将密钥粘贴进聊天、网页或 `.env.example`。当前传输只支持固定官方 HTTPS 目的地，验证 DNS 全部地址、固定连接 IP、校验 TLS/SNI、拒绝重定向；Cloud 网络密钥代理的实际兼容性仍需单独验收。

每段请求携带稳定 ID、文体与任务术语/必要上下文；严格 JSON schema 之外仍核对完成状态、数量、ID 与非空译文。截断、拒绝、异常结构不能落盘成功。数字/术语提示和人工确认沿用现有流程，模型成功不会自动确认专业质量。

首次真实测试累计预算已确认 1 美元，含全部请求、并发与重试；这不是永久的每篇费用限制，也未授权本轮真实试跑。每次请求前按完整输入的保守上界及最大输出预留，不足不发送；有效 usage 按保守费率对账，未知/失败/取消保留预留，不自动退款或重置。账本保存在 SQLite，重启必须重新明确启用，停止/再启用不清余额；单个服务进程使用，不支持多个进程共享消费账本。仅静态已定价模型可用，目录变化需另行复核；估算不是供应商账单硬限额。默认最大输出 4096 token、最高 8192，每个完整请求最多 64000 UTF-8 字节，过长请拆分。

真实连接、模型权限、计费、Cloud 代理及 Microsoft Word 人工试用仍留门禁。使用说明、验收矩阵和真实试跑步骤见 [OpenAI 第一阶段](docs/openai-phase1-plan.md)。原 [离线服务契约](docs/p3-provider-settings.md) 是 P3 历史基线，当前官方 Responses 行为以上述说明为准。

## 数据与运行边界

SQLite 默认位于 `.data/workbench.sqlite`，包含原文、译文及规范化 DOCX 结构/预检查报告；原始上传 ZIP 不落盘。数据库无应用级加密，请按敏感 IR 材料管理本机数据和下载文件。`.data`、`.env`、运行日志及原始测试产物均被 Git 忽略。

未来凭据仅由服务端管理，见 `.env.example`；本轮不配置。自动配置/列表/详情读取为独立串行轮询，5 秒期限覆盖响应正文；慢成功可生效，切换或卸载取消旧读取。专业界面的请求另有 15 秒等待限额，停止等待不代表服务端回滚，需重新读取确认。服务重启将中断任务标为已取消，可手动重试。

未保存的网页草稿不能保证刷新恢复。当前不做 PDF、OCR、邮件账户接入、自动发送、多人协作、公开部署或模型技术解释。V1 试用仍需未来确定供应商/凭据/预算、Microsoft Word 人工检查与访问方式，见 [试用前置和未运行评估表](docs/p3-evaluation.md)。
